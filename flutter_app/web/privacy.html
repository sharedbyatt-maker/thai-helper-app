ကိုယ်ရေးအချက်အလက်နဲ့ အသိပေးမှု

နောက်ဆုံးပြင်ဆင်ရက် — ၂၀၂၆ အောက်တိုဘာ ၁၈

ကိုယ့်ငွေတွက်ချက်မှုနဲ့ မှတ်တမ်း

ကိုယ်ဖြည့်တဲ့ ငွေပမာဏ၊ စဉ်းစားထားတဲ့ရက်နဲ့ ကိုယ့်ငွေလဲမှတ်တမ်းတွေကို ဒီဖုန်းရဲ့ browser ထဲမှာပဲ သိမ်းထားတယ်။ ဒီအချက်အလက်တွေကို noti ပို့တဲ့ server ဆီ မပို့ပါဘူး။ Browser data ရှင်းလိုက်ရင် ပျောက်နိုင်လို့ လိုအပ်တဲ့ မှတ်တမ်းဖိုင်ကို ကိုယ်တိုင် ထုတ်သိမ်းထားနိုင်တယ်။

ကိုယ့်ငွေစာရင်း

ဝင်ငွေ၊ သုံးငွေ၊ အိမ်ပို့ပြီးငွေ၊ စာရင်းမစခင်ရှိငွေနဲ့ ဖယ်ထားငွေအစီအစဉ်တွေကို ဒီစက်ရဲ့ browser/app ထဲမှာပဲ သိမ်းတယ်။ Admin နဲ့ server ကို မပို့ပါဘူး။ ဘတ်သုံးငွေနဲ့ ကျပ်ရငွေကို သီးခြားသိမ်းပြီး နောက်နေ့ဈေးပြောင်းတာနဲ့ မှတ်တမ်းဟောင်းတွေကို မပြောင်းပါဘူး။ ကိုယ်တိုင် Backup ဖိုင်ယူတာ၊ စာကူးတာ လုပ်မှ ကိုယ်ပိုင်ငွေစာရင်းတွေ ပါသွားမယ်။ Backup ပြန်ထည့်တဲ့အခါ လက်ရှိကိုယ့်ငွေစာရင်းကို အစားထိုးဖို့ အရင်အတည်ပြုရတယ်။ ငွေလဲမှတ်တမ်းနဲ့ နေ့စဉ်ဈေးကို မပြောင်းပါဘူး။

ဖုန်း Notification

ကိုယ်တိုင် ခွင့်ပြုပြီး “ဖုန်း noti ဖွင့်မယ်” နှိပ်မှ ဖွင့်ပေးတယ်။ ဈေးနှုန်းနဲ့ ကြေညာချက် အသစ်တင်ရင် အသိပေးဖို့ browser ရဲ့ push ချိတ်ဆက်လိပ်စာ၊ encryption key တွေနဲ့ ကိုယ့်စက်ကို စီမံနိုင်မယ့် လျှို့ဝှက် token ရဲ့ hash ကို server မှာ သိမ်းတယ်။ ကိုယ်ပိုင်ငွေပမာဏ၊ မှတ်တမ်း၊ အမည်နဲ့ ဖုန်းနံပါတ် မပို့ပါဘူး။

Noti ပိတ်လိုက်ရင် push လိပ်စာနဲ့ key တွေကို ဖယ်ပေးတယ်။ ပို့မရတဲ့ သက်တမ်းကုန်ချိတ်ဆက်မှုတွေကိုလည်း ဖယ်ပေးတယ်။ စက်အမည်မပါသော ချိတ်ဆက်မှုရည်ညွှန်းနံပါတ်ကို ရက် ၃၀ အထိ ထိန်းထားနိုင်တယ်။ ပိတ်တဲ့အချိန် လိုင်းမရရင် browser က အရင်ဖြုတ်ပြီး လိုင်းပြန်ရတဲ့အခါ server စာရင်းကို ရှင်းပေးတယ်။

အသိပေးမှုစာတွေကို ကိုယ့် browser ရဲ့ push ဝန်ဆောင်မှုကနေ ဖြတ်သန်းပို့တယ်။ ဖုန်းရဲ့ Notification Settings၊ Focus / Do Not Disturb နဲ့ internet အခြေအနေကြောင့် ပို့ပြီးချင်း မပြနိုင်တာ ရှိနိုင်တယ်။ App ထဲက အသိပေးမှုနေရာ သို့မဟုတ် ဖုန်း Settings မှာ အချိန်မရွေး ပိတ်နိုင်တယ်။

Telegram အသိပေးမှု

Telegram မှာ Start နှိပ်ပြီး အသိပေးမှု ဖွင့်ထားရင် စာပို့နိုင်ဖို့ Telegram chat ID နဲ့ ကိုယ်ရွေးထားတဲ့ ဈေးအသိပေးမှုကို သိမ်းထားတယ်။ Bot ထဲက /stop နဲ့ ပိတ်နိုင်တယ်။ ဒါက Admin ခွင့်ရတာ မဟုတ်ပါဘူး။ Telegram သုံးစွဲမှုအတွက် Telegram ရဲ့ ကိုယ်ရေးအချက်အလက်စည်းမျဉ်းတွေလည်း သက်ဆိုင်တယ်။

ဈေးနှုန်းအချက်အလက်

ဒီ App က ငွေလဲနှုန်းအချက်အလက်နဲ့ ငွေတွက်ပေးတဲ့ကိရိယာ ဖြစ်တယ်။ ငွေလွှဲပေးတာ၊ ငွေလဲပေးတာ မလုပ်ပါဘူး။ တကယ်ငွေလဲမယ့်အချိန်မှာ နောက်ဆုံးနှုန်းကို ငွေလဲသူဆီ ပြန်စစ်ပေးပါ။
